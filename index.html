Selected work

07

  1. A medical portfolio system that turns doctors' handwritten prescriptions into searchable patient records. I built the OCR pipeline on AWS Textract and the retrieval layer on PostgreSQL with pgvector and Pinecone, which reached about 95% retrieval accuracy. A fine-tuned LLaMA chatbot books appointments at 88–90% accuracy. Published as first author in Springer CCIS.

    Flask · React · PostgreSQL · pgvector · Pinecone · MongoDB · AWS Textract

    Read the paper ↗

  2. A geopolitical market signal engine. It ingests news, extracts entities and sentiment with LLaMA 3, and feeds those features to an XGBoost model that produces directional signals across 24 financial assets, at 75–79% directional accuracy under chronological validation. A FAISS index over 26,000 news passages handles retrieval, and tuning lifted evidence-grounded answer accuracy from 72% to 86% on 180 annotated queries.

    Python · LangChain · LLaMA 3 (Groq) · FAISS · XGBoost · FastAPI · Docker

  3. Started as a 48-hour hackathon build that took 3rd place at HackMIT (MIT-WPU). I later turned it into a proper multi-label classifier over 35,000 comments and six toxicity categories. A fine-tuned RoBERTa with class-weighted loss reached 0.82 macro-F1, up from 0.74 for a TF-IDF baseline.

    PyTorch · Hugging Face · scikit-learn

  4. A UCD team project pairing ARIMA for the linear structure of a price series with XGBoost on the residuals. With rolling-origin validation over eight years of data, the hybrid cut MASE from 0.96 (ARIMA alone) to 0.84. Presented as a co-authored research poster.

    Python · statsmodels · XGBoost · pandas

  5. An encrypted real-time chat app with authentication and live translation. I built the WebRTC video calling, and we tested it with 25+ concurrent users. Published in IJIRCCE.

    Flask-SocketIO · WebRTC · WebSockets

  6. A panel-data study of whether issuing green bonds actually moves a company's ESG performance, using OLS with fixed effects.

    Python · panel data · fixed effects

  7. An OpenCV pipeline built for crowded Indian traffic scenes, with text extraction running on AWS and results stored in MongoDB.

    OpenCV · AWS EC2 / S3 / IAM · MongoDB
